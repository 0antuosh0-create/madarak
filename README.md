# مدارک (Madarak) ⚡

> **پلتفرم جامع، تعاملی و یکپارچه آموزش مهندسی مدار و سیستم‌های انرژی الکتریکی ۱ به زبان فارسی**  
> بر پایه کتاب کلاسیک و مرجع دانشگاهی *«نظریه اساسی مدارها و شبکه‌ها»* (تألیف چارلز دسور و ارنست کوه / ترجمه رسمی **دکتر پرویز جبه‌دار مارالانی** — انتشارات دانشگاه تهران) و مراجع استاندارد بررسی سیستم‌های قدرت ۱.

🔗 **مشاهده نسخه آنلاین (GitHub Pages):**  
[https://0antuosh0-create.github.io/madarak/](https://0antuosh0-create.github.io/madarak/)

## 🌟 ویژگی‌های برجسته پلتفرم

- 📖 **۴۱ درس تحلیلی و پیوسته** در قالب **۸ فصل تخصصی** از مبانی مدارهای فشرده تا پخش بار شبکه‌های قدرت.
- 🖼️ **گراورها و اشکال اصل کتاب دکتر جبه‌دار** به همراه تصاویر معتبر و باکیفیت مهندسی از مراجع بین‌المللی (Wikimedia Commons و MIT OpenCourseWare).
- 📐 **رندر ریاضی با موتور قدرتمند KaTeX** با پشتیبانی کامل از معادلات دیفرانسیلی، انتگرالی، فازورها و ماتریس‌ها.
- 📝 **مسائل و سوالات تشریحی امتحانی** به همراه پاسخ‌های تشریحی و گام‌به‌گام برای ارزیابی عمیق مفاهیم.
- 🎯 **آزمونک‌های مفهومی (Quiz)** در انتهای هر درس برای تثبیت آموخته‌ها با بازخورد آنی.
- 📑 **جعبه خلاصه و جمع‌بندی جامع درس** شامل ایده‌های بنیادین، فرمول‌ها و دام‌های تستی/امتحانی.
- 📑 **فرمول‌نامه سریع (Cheatsheet)** با کلید میانبر `Ctrl+K` برای دسترسی فوری به تمامی فرمول‌ها و قضایای مدار.
- 💾 **سیستم ذخیره و پشتیبان‌گیری پیشرفت تحصیلی (Backup/Restore)** به صورت فایل محلی بدون نیاز به لاگین.
- 🌓 **پشتیبانی دوگانه از تم تاریک و روشن (Dark / Light Mode)** با کنتراست استاندارد و محافظ چشم.
- 📱 **طراحی کاملاً واکنش‌گرا و بهینه برای موبایل و تبلت** با فونت اصیل فارسی **وزیرمتن (Vazirmatn)** و اصول تایپوگرافی RTL.

## 📚 سرفصل‌های آموزشی دوره (Curriculum)

| فصل | عنوان فصل | تعداد درس |
| :---: | :--- | :---: |
| **۱** | مدارهای فشرده، قوانین کیرشف و مبانی توان و انرژی | ۶ درس |
| **۲** | رفتار سینوسی متناوب، توان مختلط و شبکه‌های سه‌فاز | ۵ درس |
| **۳** | عناصر مداری و مدل‌سازی شبکه‌ها (مقاومت، خازن، سلف، منابع وابسته) | ۵ درس |
| **۴** | دستگاه پریونیت (Per-Unit) و مدل‌سازی ترانسفورماتورها | ۴ درس |
| **۵** | پارامترها و مشخصات خطوط انتقال توان الکتریکی | ۶ درس |
| **۶** | روش‌های سیستماتیک تحلیل شبکه و ماتریس ادمیتانس شین ($Y_{bus}$) | ۵ درس |
| **۷** | قضایای اساسی شبکه و تقویت‌کننده‌های عملیاتی (Op-Amps) | ۵ درس |
| **۸** | روش‌های محاسباتی، شبیه‌سازی با SPICE و الگوریتم‌های پخش بار | ۵ درس |

## 🛠️ فناوری‌های مورد استفاده (Tech Stack)

- **Frontend:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS (با فونت‌های فارسی استاندارد و دارک‌مود)
- **Math Engine:** KaTeX
- **Icons:** Lucide Icons
- **Deployment:** GitHub Pages (CI/CD via GitHub Actions)

## 🚀 راه‌اندازی و توسعه محلی (Local Development)

```bash
# کلون کردن مخزن
git clone https://github.com/0antuosh0-create/madarak.git
cd madarak

# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه محلی
npm run dev

# ساخت بسته بهینه‌سازی شده تولید (Production Build)
npm run build
```
